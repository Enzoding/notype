# P0 / P1 交付说明

版本：0.2.1。默认生产数据目录不变，BYOK 仍无需账户。

## 使用

工作台第一个模块只检查两项：当前渠道的 API Key 是否已配置，以及麦克风和辅助功能权限是否已完成；两项完成显示 OK。模型、地址、连接测试和设备状态不在工作台首屏展示。

偏好设置 → AI 渠道：选择 Vercel 或 OpenRouter，保存该渠道的 Key 与模型。全部能力使用同一当前渠道；地址固定由渠道决定，不能编辑。原先分阶段配置升级时沿用转写渠道，两套密钥和模型保留。模型目录按需展开，每类最多展示六项，其余可填写 ID。测试操作仍可能产生渠道费用，不作为首页配置是否齐全的条件。

未完成的口述位于偏好设置 → 录音与恢复。重试只处理未完成阶段，使用当前选定渠道/模型，已完成 ASR 片段不会重发。恢复结果进入历史供复制，不自动粘贴。普通录音仍保留润色失败使用原文的行为。取消是停止处理并保留草稿；“删除草稿”才删除其恢复文件。

## 数据与恢复

- 新增 `tasks/` 音频日志和 JSON 任务；现有历史表不改写，新增 `task_history` 映射表以保证重试不重复建历史。
- 原始日志每两秒同步一次；崩溃/掉电可能丢失最后尚未成功同步的尾段，不能保证零丢失。
- 成功后按“保存录音”设置归档音频，再清理任务缓存；失败/中断草稿保留七天，在启动或刷新恢复任务时清理。即使关闭长期保存录音，处理期间也会有本地安全缓存。
- 数据库、录音和任务日志备份时应一起复制。元数据损坏时先备份目录，不用删除历史来排查。
- Keychain 写入和读回验证失败时保留旧凭据；成功后只清理旧 API key 字段/环境赋值。首次升级可能出现系统钥匙串授权提示。

## 已知边界

- 长稿润色按不超过 1000 字的段落分段并保存成功片段；渠道报告截断时回退完整原文。
- 目前是录完再按连续 30 秒切片转写；尚未加入静音切分、重叠边界识别或实时字幕。长段接缝处的识别质量需要真机与真实渠道评估。
- 已发送的 blocking HTTP 请求不能立即中止；取消会阻止后续请求、重试和粘贴，上游仍可能计费。网络超时不自动重发，手动重试也可能重复产生渠道费用。
- 通用自定义 OpenAI 服务、账号登录、云端代理与订阅不属于本次交付。当前版本仅使用渠道固定地址。
- 模型目录展开后最多展示每类 6 项，其余可填写 ID；模型和价格随渠道变化，默认值不代表实测推荐。

## 0.2.1 滚动与界面复查

- 设置按主题条件挂载，隐藏主题不创建表单、开关、模型列表或恢复行。
- 渲染不调用系统代理探测、权限查询或文件扫描；权限状态每两秒在协调循环中更新，界面只读缓存。
- 2000 个合成模型的目录测试确认每类最多返回 6 个可挂载条目；目录关闭时不创建模型按钮。恢复列表仍分页，复制正文移至点击时执行。
- 独立预览包实测：首页缺失项可进入设置；偏好设置实际滚动后主题导航保持固定。未进行 60/120Hz 帧耗时量化，不据此承诺帧率。
- 麦克风权限读取使用 [Apple AVFoundation 授权状态 API](https://developer.apple.com/documentation/avfoundation/avcapturedevice/authorizationstatus(for:))；查询不会请求权限或开始录音，授权入口由用户主动点击。

最终预览已确认：首页当前状态模块只有 API Key 和所需权限两行，未授权的麦克风、辅助功能分别在权限行说明；不展示模型、地址、连接测试或设备检测状态。未代替用户批准真实授权请求。

## 0.2.2 收尾验证（合成数据，不含真机）

- `cargo fmt --check`、`cargo clippy --all-targets --locked`（零警告）、`cargo test --locked`（61 项）通过；新增项为 Vercel 请求线上契约测试。该测试只固定当前客户端发出的请求形态，不证明 Vercel 服务端仍接受它，仍需真实 Key 的调用确认。
- 十分钟 48 kHz 立体声合成基线（release、一次运行、恒定样本，仅反映本机该次结果）：写盘约 0.38 秒；20 个分片，单片编码最慢约 5 毫秒；进程常驻内存约 10 → 17（写盘后）→ 44 MB（全部分片编码后）；`audio.raw` 约 219.7 MB，编码后 WAV 合计约 18.3 MB。
- 观察：原始日志按设备格式保存，十分钟约占 220 MB 磁盘，失败草稿保留七天时需要关注磁盘占用；磁盘满时的行为仍需真机验证。
- 该基线不含真实麦克风回调、UI 帧停顿、网络上传和停止到出字时间，这些仍未测量。

## 0.2.4 Vercel 真实渠道冒烟（合成语音）

用 `say` 生成的英文、中文各一段（16 kHz 单声道 WAV，约 7 与 9 秒），通过 `providers::live` 对真实 Vercel AI Gateway 运行，Key 取自本机 `.env.local`（已被 git 忽略，未写入任何文件或日志）。共约 8 次小额请求。

- 聊天连接成功（约 1.1 秒），模型目录返回 330 项。
- 默认转写模型 `microsoft/mai-transcribe-2` 成功转写两段；英文去除了开头的 “Um”，中文保留了“嗯，那个”等口癖（由润色阶段去除），其余内容完整，“Notype” 术语两段均识别正确（带热词）。
- 默认润色模型 `deepseek/deepseek-v4.1-flash` 成功去除口癖并保持原语言；中文润色在中英文之间补了空格，符合 `space_cjk`。
- 术语提取返回合法 JSON。
- 结论：当前 Vercel 协议头、请求体与响应解析与真实服务一致。样本为合成语音，不代表真人录音的识别质量、延迟和长录音（分片）表现。
- 未验证：OpenRouter（无 Key）；`ai-gateway` 对 10 分钟/多分片的真实表现；真机端到端流程。
